Y-TEC 付箋 1.2.0
==================

1. YTEC-Sticky-Note.exe を起動します。
2. 初回起動時にWindowsの自動起動へ登録されます。
3. 本文、装飾、背景、位置、サイズは data\sticky-note.json へ自動保存されます。

書式
----
上部のボタンから、太字、斜体、下線、取り消し線、中央揃え、箇条書きを使えます。
フォント欄ではPCにインストールされているフォントを検索でき、よく使うフォントは一覧の先頭に★付きで表示されます。

タスクトレイ
------------
アプリはタスクバーに表示せず、通知領域へ専用アイコンを表示します。
最小化または右上の×で付箋を隠し、トレイアイコンのダブルクリックで再表示できます。
完全に終了するときは、トレイアイコンを右クリックして「終了」を選んでください。

持ち運ぶとき
------------
このフォルダー全体をUSBメモリやGoogle Driveへコピーしてください。
dataフォルダーも一緒に移動すると、付箋の内容と設定を引き継げます。
移動後に一度手動で起動すると、自動起動の登録先が新しい場所へ更新されます。

注意
----
- 自動起動はGoogle Driveのプロセスではなく、アプリと保存データの読み取り・書き込みが可能になるまで最大10分間、エラーを出さずに待ちます。
- 10分を超えてもアプリ一式を読み取れない場合は、その回の自動起動を静かに見送ります。
- 自動起動を止める場合は、画面下部の「自動起動」をオフにしてください。
- 保存データは暗号化していません。
- data\sticky-note.json.bak は直前保存のバックアップです。
